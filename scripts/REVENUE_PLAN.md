# 여행심플 월 순이익 500만원 실행 기준

기준일: 2026-10-23 KST. 목표는 운영비 차감 후 세전 순이익 월 5,000,000원. 달성 보장 또는 실적 예측이 아니다.

## 확인된 기반
- Metricool 브랜드 7581375: Instagram/Threads esim_simpletravel, YouTube 연결.
- 10월 20~23일 조회 결과에 나타난 콘텐츠 3건 노출은 각각 3/5/63, 상호작용 0. 전체 플랫폼 실시간 총계는 아니다.
- GA4에는 동의 후 구매 링크 클릭 수집이 있지만 결제 완료 데이터는 없다.
- eSIMOA 상품 API와 허용된 구매 URL이 구현되어 있다. API 연결만으로 제휴 승인·주문 귀속·정산을 입증하지 않는다.
- 현재 실제 주문, 승인 수수료, 환수, 지급 내역, 광고비는 미확인이다. 0원으로 치환하지 않는다.

## 계산 기준
월 이익 = 승인 수수료 - 환수·수수료 비용 - 광고비 - 도구비 - 기타 운영비.
동일 주문의 환수는 승인 수수료 집계와 중복 차감하지 않는다. 보류 수수료와 실제 입금은 별도 열에 기록한다.
건당 확정 순수수료 = (승인 수수료 - 환수·수수료 비용) / 해당 주문 수.
필요 주문 = ceil((5,000,000 + 월 광고비 + 도구비 + 기타 운영비) / 건당 확정 순수수료).
예시 가정: 월 비용 300,000원이면 건당 2,000원에 2,650건, 5,000원에 1,060건, 10,000원에 530건 필요. 실제 수수료가 아니다.
구매 전환율을 가정 3%로 두면 각 88,334 / 35,334 / 17,667회의 판매처 유효 클릭이 필요하다. 사이트 방문수와 다른 지표다. GA4 동의 표본 클릭으로 전체 전환율을 단정하지 않는다.

## 실행 순서
1. eSIMOA 관리자에서 제휴 활성화 여부, 실제 referral 식별자, 수수료·환수·정산 조건 확인. 승인 수수료와 클릭을 익명 집계 형태로 내보낸다. 고객 이름·연락처·주문 식별자는 공개 저장소에 넣지 않는다.
2. 운영 사이트에서 일본/대만/베트남/태국/미국 각각 API 응답, 모바일 비교, 판매처 이동, referral 보존을 점검한다. 본인 구매 인정 여부가 확인되지 않은 자기 구매로 검증하지 않는다.
3. 콘텐츠별 제한된 UTM 사용: instagram/threads/youtube, social, ig-YYYYMMDD/threads-YYYYMMDD/shorts-YYYYMMDD. 기존 유튜브 shorts-launch-YYYYMMDD도 보존한다.
4. 일본 여행 준비·데이터량·설치 시작 조건 콘텐츠로 소규모 7일 실험. 최신 공식 근거와 실제 상품 조건 검토 후 게시한다. 가격·최저가·속도·수익을 근거 없이 약속하지 않는다. 구매 행동 유도는 국가/기간별 비교 페이지로 연결한다.
5. 7일 단위로 노출 → 사이트 유입 → 판매처 클릭 → 확인된 승인 주문 → 확정 수수료를 비교한다. 데이터가 없으면 미확인으로 표시한다. 노출이 적으면 소재, 유입 후 이탈이면 페이지, 클릭 후 구매 부진이면 상품/가격/귀속을 점검한다.
6. 판매처 보고서의 집계 단위가 국가/채널/캠페인을 지원하는 범위에서만 귀속한다. 지원하지 않는 귀속이나 매출 API는 만들어내지 않는다.

## 비용 확대 기준
구독·광고 예산은 아직 미정이다. 신규 지출을 집행하지 않은 상태다.
유료 광고는 실제 제휴 정산 조건과 주문당 마진, 구매 귀속이 확인된 후에만 실험 예산을 배정한다.
손익분기 CPC = 판매처 클릭→승인 주문 전환율 × 건당 확정 순수수료. 사이트 유입 광고에서는 사이트→판매처 클릭률도 곱한다.
규모 확대는 환수 반영 후 기여이익이 양수이고, 보고 지연·표본 크기를 검토한 다음 결정한다. 도구 추가보다 기존 무료 연결을 우선한다.
